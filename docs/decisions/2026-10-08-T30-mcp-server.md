# T30: a stdio MCP server (`bigarrow mcp`)?

Date: 2026-10-08. Decision: **not now.**

The agents this project serves, Claude Code and Codex, run shell commands and load the
`big-arrow` skill (verified: both list the skill, see `docs/skill-tests/`). Every capability is
one `bigarrow` command with `--json` output and documented exit codes, which is what an MCP
tool would wrap. No consumer that cannot run a shell command was named. An MCP server would add
a long-running process, a protocol dependency and a second interface to keep in sync, for no
current user.

Revisit when a concrete consumer appears (for example a desktop chat app without shell access);
the wrapper would be `point`, `start`, `stop`, `doctor` mapped one to one onto the CLI.
