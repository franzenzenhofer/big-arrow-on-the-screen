T09Process model: foreground run, pid file, bigarrow clear dismisses, SIGTERM/SIGINT clean exit

Done · issue

The CLI process owns the arrow; pid files in $TMPDIR/bigarrow, stale ones removed; stop/clear [--all|--pid]; SIGTERM/SIGINT fade out; --detach and start return once the child is on screen. Tested: detach and stop under 0.5 s on test Macs, two arrows and stop --all.

The CLI process itself owns the overlay for its lifetime (no daemon, no helper app; the drawing path needs no TCC identity so a bundled app buys nothing here - contrast Nameplate's app plus JSON handoff design, which exists because its app holds state).
